# Visual Assets Context

This workspace manages the visual identity of Sheeting, including icons, screenshots, and design references.

## Asset Categories
- **Icons:** SVGs in `/assets/extracted_svgs/` and `/assets/new_svgs/`.
- **Screenshots:** Reference images of the original "App do Breno" design for high-fidelity matching.
- **Public:** Static assets used in the PWA and index.html.

## Design Standards
- **Theme Support:** Assets must support both Light and Dark themes.
- **Status Colors:** Strictly use the HEX codes defined in `GEMINI.md`.
- **Fidelity:** Refer to `assets/drive-download-...` for the source of truth on layout and spacing.

## Guidelines
- **SVG Optimization:** Keep SVGs clean and use CSS variables for coloring where possible.
- **Versioning:** Preserve original assets; create new versions for modifications.
